Create a new React web application called Workout Tracker. Use Supabase for authentication and data storage. The app should use two related tables: workout_sessions (id, user_id, session_date, title) and workout_exercises (id, session_id, exercise_name, sets, reps, weight, notes). Users should be able to create workout sessions, add exercises to them, view their past workouts, and delete sessions. Include user authentication with email/password.
